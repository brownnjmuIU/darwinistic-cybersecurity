Does the attacker get better with practice?

Switch the Attacker box above between Fixed guesses and Learned (RL) and run it again: the learned attacker fools more people. The chart shows why. Over thousands of practice runs on made-up people, the learning attacker (blue) steadily improves while the fixed one (orange) never does.

Which defenses still work when the attacker evolves?

Turn on a defense with the Defenses box above and run again: fewer people fall for it. But a learning attacker adapts, so we also let it keep practicing against each defense for 2,000 more made-up people and measured whether it found a way around.

Finding: narrow defenses get routed around; broad ones hold. Every defense in our playbook weakens several tricks on every app, so the attacker had nowhere better to go and won back nothing. A control defense that only blocks one trick (pretending to be someone important) was routed around: the attacker dropped that trick completely and switched to others.
